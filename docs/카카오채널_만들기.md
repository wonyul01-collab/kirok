# 키록 카카오톡 채널 만들기 (대표님 직접, 약 20분)

카카오톡 채널은 대표님 카카오 계정으로만 만들 수 있습니다. 만든 뒤 채널 주소 한 줄만 알려 주시면 사이트의 카톡 단추가 바로 켜집니다.

## 1. 채널 만들기
1. 컴퓨터에서 https://center-pf.kakao.com 접속 → 대표님 카카오 계정으로 로그인
2. **새 채널 만들기**
3. 입력값
   | 칸 | 넣을 값 |
   |---|---|
   | 채널 이름 | 키록 |
   | 검색용 아이디 | 키록 (없으면 kirok, kirokapp 순서로) |
   | 프로필 사진 | 앱 아이콘 `kirok_site\assets\icon.png` (1024×1024) |
   | 소개 문구 | 아이 키 기록과 예상 성인 키 범위. 진단이 아닌 참고 정보입니다. |
   | 카테고리 | 건강 > 건강관리 (없으면 생활 > 생활정보) |
4. **확인** → 채널 생성 완료

## 2. 프로필 꾸미기
- 관리자 센터 → 프로필 설정
  - 배경 사진: `kirok_site\og.jpg`
  - 버튼: '웹사이트' → https://wonyul01-collab.github.io/kirok/
  - 소개 아래 링크: 사용 설명서 https://wonyul01-collab.github.io/kirok/manual/
- **채널 공개** 와 **검색 허용** 켜기

## 3. 1:1 채팅 켜기
- 관리자 센터 → 채팅 → **채팅 사용 설정 ON**
- 운영 시간: 평일 10:00~18:00 (밖에서는 자동응답만)
- 운영 시간 외 안내 문구: "지금은 상담 시간이 아니에요. 남겨 주시면 평일 10~18시에 답해 드릴게요. 자주 묻는 질문은 https://wonyul01-collab.github.io/kirok/support/ 에서 바로 볼 수 있어요."

## 4. 자동응답(키워드 10개)
관리자 센터 → 채팅 → 자동응답 → 키워드 응답 추가. 답변은 사이트 `assets/faq.js` 와 같은 내용입니다(바꾸면 둘 다 고침).

| # | 키워드(여러 개 넣기) | 답변 |
|---|---|---|
| 1 | 설치, 다운로드, 플레이스토어, 아이폰 | 키록은 구글 플레이 출시를 준비하고 있어요(2026년 12월 예정). 그 전에는 https://wonyul01-collab.github.io/kirok/app/ 에서 웹 체험판을 바로 써 볼 수 있어요. 아이폰판은 아직 일정이 정해지지 않았고, 웹 체험판은 아이폰에서도 열려요. |
| 2 | 정확도, 오차, 맞나요, 예측 | 키록은 한 숫자 대신 범위를 보여 드려요. 부모 키만으로 계산하면 가운데 값에서 위아래 8cm, 같은 조건의 아이 10명 중 9명이 이 범위에 들어가도록 잡은 폭이에요. 한국 부모·자녀 2,586쌍 연구(Kim 외 2024)의 계수를 지금 부모 세대에 맞춰 썼어요. 진단이 아닌 참고 값이에요. |
| 3 | 가격, 결제, 유료, 구독 | 예측·기록·성장 곡선·성장 속도 신호등·오늘 미션·백업은 무료예요. 자세한 리포트는 한 번 2,900원, 평생 29,000원, 연 19,900원, 월 4,900원 중에서 고를 수 있어요. 결제는 구글 플레이 결제로만 받아요. |
| 4 | 환불, 해지, 취소 | 구독 해지는 구글 플레이 앱 → 프로필 → 결제 및 정기 결제 → 정기 결제에서 언제든 할 수 있어요. 환불은 구글 플레이 환불 규정을 따르고, 구매 직후라면 구글 플레이에서 직접 요청할 수 있어요. 그 밖의 경우는 여기 남겨 주시면 확인해 드려요. |
| 5 | 개인정보, 저장, 서버, 동의 | 키·몸무게·부모 키는 휴대폰 안에만 저장되고 서버로 보내지 않아요. 실명·전화번호·이메일·위치는 받지 않아요. 만 14세 미만은 보호자 동의 뒤에만 기록해요. 함께하기를 켜면 도전에 필요한 별명·성별·태어난 해와 달, 운동·잠 체크만 서버에 올라가요. |
| 6 | 탈퇴, 삭제, 지우기 | 키록은 회원 가입이 없어요. 오늘 화면 맨 아래 '가족·설정'에서 '이 기기의 모든 기록 지우기'를 누르거나 앱을 지우면 기록이 모두 사라져요. 함께하기 서버 기록 삭제는 여기 남겨 주세요. |
| 7 | 기기 변경, 백업, 옮기기, 새 폰 | 예전 휴대폰 오늘 화면 맨 아래 '기록 백업·불러오기' → '백업 글 보내기'로 나온 글 전체를 보관하고, 새 휴대폰 첫 화면 '다른 휴대폰의 기록 불러오기'에 붙여 넣으면 돼요. 백업은 무료예요. |
| 8 | 초대, 코드, 함께, 가족 도전 | '함께' 탭에서 도전을 만들거나 고른 뒤 '초대'를 누르면 초대 코드가 나와요. 받은 사람은 키록 설치 → '함께' 탭 → '받은 초대 코드로 참여'에 코드를 넣으면 돼요. |
| 9 | 오류, 에러, 안돼요, 멈춤 | 불편을 드려 죄송해요. 어떤 화면에서 무엇을 눌렀을 때인지, 휴대폰 기종을 함께 남겨 주시면 빨리 고칠게요. |
| 10 | 신호등, 빨강, 성장 속도, 상담 | 최근 기록 사이에 자란 키를 1년으로 환산해 같은 나이 가운데 성장량(질병관리청 2017 성장도표)과 견줘요. 만 4세 이후 6개월 넘는 간격에서 1년 4cm 이하이면 '소아과 상담을 권해요'가 떠요. 진단이 아닌 상담 권유 기준이에요. |

- 기본 인사(채팅방 처음): "안녕하세요, 키록입니다. 설치·정확도·가격·환불·개인정보·백업·초대·오류 중 궁금한 낱말을 보내 주시면 바로 답해 드려요. 사용 설명서: https://wonyul01-collab.github.io/kirok/manual/"
- 모든 답변 끝에 붙일 한 줄(의료 질문 대비): "키록의 예측과 신호는 진단이 아닌 참고 정보예요. 걱정되면 소아청소년과와 상담해 주세요."

## 5. 사이트에 연결하기
1. 관리자 센터 → 채널 홈 → 채널 URL 복사 (예: `http://pf.kakao.com/_AbCdE`)
2. 이 주소를 클로드에게 알려 주시면 `kirok_site\site.config.js` 의 `KAKAO_CHANNEL_URL` 에 넣고 다시 올립니다.
   - 직접 고칠 때: `KAKAO_CHANNEL_URL: 'http://pf.kakao.com/_AbCdE'` 로 바꾸고 저장 → 올리기.
3. 사이트의 카톡 단추가 '카카오톡 채널 준비 중'에서 '카톡으로 묻기'로 바뀌고 `http://pf.kakao.com/_AbCdE/chat` 으로 열립니다.

## 주의
- 의료 상담(진단·약·치료)은 답하지 않고 소아청소년과 상담을 권합니다.
- 아이 실명·사진은 받지 않도록 안내합니다.
